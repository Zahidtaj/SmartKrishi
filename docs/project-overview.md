# Project Overview

SmartKrishi is a VTU Community Project focused on practical agricultural decision support for Karnataka farmers, students, and extension educators.

## Problem Statement

Farmers choosing crops across Karnataka's diverse agro-climatic zones face fragmented information across soil test laboratories, seasonal advisories, irrigation constraints, and crop economics. Purely machine-learning crop demos commonly fail in practice because they ignore regional crop restrictions, seasonal calendars (Kharif/Rabi/Zaid), and water deficits—or present black-box crop labels without explaining risks or missing data.

## Core Objectives

1. Support structured, region-aware input capture across Karnataka districts, taluks, and NARP agro-climatic zones.
2. Allow farmers to enter laboratory Soil Health Card data, estimates, or continue transparently in reduced-information mode when soil tests are missing.
3. Combine Random Forest classification with configurable hard agronomic constraints so ML never overrides critical water, pH, season, or regional limits.
4. Provide side-by-side crop comparison, soil-health parameter interpretation, and a source-attributed Knowledge Centre in English and Kannada.
5. Maintain strict honesty regarding prototype limitations, non-live weather/market feeds, and illustrative economic assumptions.
